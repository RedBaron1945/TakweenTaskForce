# منظومة متابعة طلاب تكوين النسيم 🌿

نظام إلكتروني خفيف وسريع مصمم خصيصاً لمشرفي ومعلمي الحلقات لتسجيل ومتابعة حضور وورد طلاب برنامجي أسرة **باموسى** وأسرة **أكرم**، مع احتساب النقاط وتوليد التقارير وتوفير مزامنة سحابية لحظية.

---

## 🌟 الميزات الرئيسية

- **الرصد اليومي السريع والمباشر**:
  - رصد الحضور والغياب والاستئذان بلمسة واحدة.
  - متابعة الحفظ الجديد والمراجعة اليومية.
  - رصد حضور الدروس العلمية، اللقاءات الأسرية، والبرامج الفردية حسب كل يوم من أيام الأسبوع.
  - أزرار سريعة مثل "⚡ تم الكل" وتسجيل الحضور الجماعي، وخاصية الإلغاء بالنقر المتكرر.
  - فلاتر مرنة: (الكل، غير مسجل / ناقص، منجز بالكامل، غياب/اعتذار).

- **لوحة المتصدرين والتحفيز**:
  - ترتيب تنازلي آلي لنقاط الأسبوع مع الميداليات ومناطق التميز.
  - وسام المتألق الأسبوعي لتكريم الطالب صاحب أعلى قفزة إيجابية في النقاط مقارنة بالأسبوع السابق.
  - بطاقات وإحصائيات مقارنة نسب الإنجاز بين الأسرتين.

- **المتابعة والتشخيص المتقدم**:
  - تشخيص فوري لنقاط الضعف ومعدلات الالتزام بالحفظ والمراجعة وحضور الدروس.
  - تحديد الطلاب الأكثر احتياجاً للمتابعة والتوجيه تلقائياً مع تفصيل أيام الغياب والتعثر.

- **تقارير واتساب وطباعة PDF**:
  - توليد رسائل واتساب فردية منسقة لكل طالب بنقاطه وأيامه مع روابط مباشرة للإرسال.
  - توليد تقرير أسبوعي شامل لكل أسرة جاهز للنسخ والإرسال.
  - قوالب طباعة مخصصة عالية الدقة لطباعة التقارير أو حفظها بصيغة PDF.

- **المزامنة والتخزين السحابي**:
  - حفظ تلقائي لحظي للبيانات محلياً وعلى قاعدة بيانات **Firebase Firestore**.
  - دعم العمل دون اتصال (Offline-first) مع ميزات تطبيق الويب المتقدم (PWA) عبر Service Worker.
  - ميزات النسخ الاحتياطي الكامل (تصدير واستيراد بصيغة JSON) لحماية البيانات.

## 📁 هيكلية المشروع

```
├── index.html                  # واجهة المستخدم الرئيسية للتطبيق
├── script.js                   # منطق التطبيق وحساب النقاط والفلاتر والتقارير
├── style.css                   # التنسيقات وتصميم واجهة المستخدم المتجاوبة
├── public/                     # الأصول الثابتة (يتم نسخها مباشرة لـ dist)
│   ├── manifest.webmanifest   # إعدادات تطبيق الويب التقدمي (PWA)
│   ├── sw.js                  # مشغل التخزين المؤقت والعمل دون اتصال (Service Worker)
│   └── robots.txt             # تعليمات منع محركات البحث من الفهرسة
├── src/
│   ├── firebaseSync.js        # طبقة المزامنة اللحظية مع Firebase Firestore
│   └── assets/images/         # شعارات وأيقونات التطبيق
├── assets/                     # أصول رسومية مساعدة (SVG)
├── metadata.json               # بيانات تعريف التطبيق في المنصة
├── firebase-applet-config.json # إعدادات مشروع Firebase المرتبط
├── firestore.rules             # قواعد الأمان لقاعدة البيانات
├── package.json                # التبعيات وأوامر التشغيل
└── vite.config.ts              # إعدادات Vite للبناء والتطوير
```

## 🔒 نموذج الأمان

بيانات الطلاب (`app_data`) محمية عبر قواعد Firestore بحيث لا يُسمح بالقراءة أو الكتابة إلا لمن يعرف رمز PIN الصحيح — معرّف المستند نفسه مشتق من تجزئة (hash) الرمز الحالي المخزّن في `system_security/access_vault`، والذي لا يمكن قراءته من المتصفح أبداً.

**ملاحظة مهمة حول حدود هذا النموذج:** هذه الحماية تعتمد على معرفة "سر" (التجزئة المشتقة من الرمز) وليست مصادقة حقيقية بهوية المستخدم. من يلتقط طلب شبكة صالح واحد (مثلاً عبر أدوات المطوّر في المتصفح أثناء استخدام شرعي) يمكنه استخراج معرّف المستند الحالي والاحتفاظ بإمكانية الوصول حتى تغيير رمز PIN التالي. هذا أفضل بكثير من الوضع السابق (وصول مفتوح للجميع بشكل دائم)، لكنه ليس بديلاً عن مصادقة حقيقية.

للحصول على حماية أقوى مستقبلاً: تفعيل Firebase Anonymous Authentication مع دالة Cloud Function صغيرة للتحقق من الرمز وتعيين Custom Claim (`verified: true`)، ثم تقييد القواعد بـ `request.auth.token.verified == true` بدلاً من مطابقة معرّف المستند.
